# Log Archive Tool

A Bash script that archives a provided log directory into a timestamped tar.gz file stored in an archives folder.

## Technologies

Shell/Bash

## Requirements

- [x] Provide the log directory as an argument when running the tool
- [x] The tool should compress the logs in a tar.gz file and store them in a new directory
- [x] The tool should log the date and time of the archive to a file

## Usage

Run the script with:

```bash
bash log-archive.sh <log-directory>
```

If you want to execute it directly:

```bash
chmod +x log-archive.sh
./log-archive.sh <log-directory>
```
