# Server Performance Stats

A simple Bash script that collects and displays key server performance metrics from the current machine.

## Technologies

Shell/Bash

## Requirements

- [x] Total CPU usage
- [x] Total memory usage (Free vs Used including percentage)
- [x] Total disk usage (Free vs Used including percentage)
- [x] Top 5 processes by CPU usage
- [x] Top 5 processes by memory usage

## Usage

Run the script with:

```bash
bash server-stats.sh
```

If you want to execute it directly:

```bash
chmod +x server-stats.sh
./server-stats.sh
```
