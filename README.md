# 🌟 Roadmap.sh DevOps Projects

These projects follow the [roadmap.sh](https://roadmap.sh/devops/projects) **DevOps Learning Path** and focus on practical operations skills: shell scripting, system automation, CI/CD pipelines, infrastructure as code, monitoring, and containerization. Each project is hands-on and incremental — starting with small scripts for collecting server metrics and progressing to full automation workflows and observability setups.
